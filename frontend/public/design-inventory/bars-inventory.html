Bars · Screen inventory

The three bars every page is built from. Each has fixed zones: constant controls sit at fixed ends and never move; only the middle slot changes from page to page, and every setting there is a dropdown chip. Utility actions are icons with their name in a tooltip; the only labelled button in a bar is its primary action.

Page level metric bar   [date range] [settings… (chips)]  ·····  [account · synced] | [Run]
Table toolbar           [view] [search]  or  [n selected · actions]  ·····  ✎ | Δ ⇅ ⏷ ▥ | ⤒ ⤓ | [Primary]
Chart bar               Title · context ⓘ    [settings… (chips)] | [line bar area] | ⋯ ⤢        (legend under the plot)

Where does a new option go? Scopes the whole page → a page bar chip. Acts on the table → a toolbar icon (in its group) or the view switch. Changes one chart → a chart bar chip. Real DOM, captured from the running app. Code: frontend/src/components/bars.
